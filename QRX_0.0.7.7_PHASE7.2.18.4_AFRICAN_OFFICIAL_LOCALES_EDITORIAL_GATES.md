# QRX 0.0.7.7 Phase 7.2.18.4 — African Official Locales & Editorial Gates

- Locales: 55
- Translation keys per locale: 826
- Added African language locales: ar, af, am, sw, so, ti, rw, rn, st, tn, ss, zu, xh, mg, ny, sn, nd, nso, ts, ve, nr, ber
- German remains the only locale marked `complete` because it is the only catalogue with a completed editorial review and explicit identical-literal allowlist.
- All other locale catalogues are deliberately marked `requires_human_editorial_review`; key parity is not presented as translation quality.
- Language selector and QRX Generals locale detection include all new locales.
- The quality gate fails if a locale is marked complete without a reviewed allowlist.

This phase intentionally avoids claiming machine-filled English copies are editorial translations.
