Privacy Center

QRX Browser keeps the QRX-Net and normal web routes explicit. Security-critical route rules are enforced by the native browser host rather than by page JavaScript.

HTTPS-only WWW

Plain HTTP navigation is rejected. Normal web addresses use HTTPS only.

ENFORCED

QRX route isolation

.qrx and qrx:// content is resolved through the local QRX resolver/cache and does not silently fall back to DNS.

ENFORCED

Local browser chrome

Tabs, address controls and route selection live in a separate local WebView from website content.

ENFORCED

Browsing-data control

Use ☰ → Clear browsing data to clear cookies, cache and other data attached to the content WebView.

AVAILABLE
The route selector changes how ambiguous input is interpreted. Explicit https://, qrx:// and .qrx addresses always retain their explicit route.
