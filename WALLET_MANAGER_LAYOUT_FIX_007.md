# QRX 0.0.7 — Wallet Manager Layout Fix

- Wallets view is now a single full-width workflow instead of the wide-screen auto-tiled dashboard layout.
- Migration Conflict Wizard, Recovery Center, Security and key import no longer compete for adjacent columns.
- Legacy network migration candidates use a dedicated responsive grid.
- Long QUB addresses wrap safely and cannot overflow into form controls or neighboring cards.
- Candidate wallet-name input and action button stay grouped in their own control column.
- On narrow windows the migration candidate layout collapses cleanly to one column.
